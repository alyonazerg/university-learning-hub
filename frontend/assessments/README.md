Hosted test pages go in named subdirectories, for example assessment-2/index.html or revision-1/index.html, with their own scripts and styles. Docker and GitHub Pages publish this directory automatically. Rebuild the Beget frontend after adding pages. In the lesson editor use /assessments/assessment-2/ or the full HTTPS URL. Backend services for a test are configured by that test's implementation; attaching a URL does not automatically synchronize scores into Moon Campus.
