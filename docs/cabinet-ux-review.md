# Учебный кабинет: UX/UI review

Проверены и исправлены основные проблемы:

- Информационная иерархия: вместо общей длинной страницы показывается один раздел. Расписание — стартовый экран, для преподавателя без групп — группы.
- Последовательное раскрытие: создание группы, списка слов и ручного занятия доступно через раскрываемое действие. Существующие данные видны прежде форм заполнения.
- Ориентация: активный раздел выделен и отмечен aria-current; навигация остаётся доступна при прокрутке. Группы скрыты для студентов.
- Согласованность: обновление и выход отделены от разделов; одинаковые отступы, подписи и размеры полей.
- Предотвращение ошибок: при отсутствии групп показана причина недоступности сохранения. Выбор группы доступен непосредственно в тематическом плане.
- Обратная связь: сообщения операций объявляются через aria-live; переход из плана к журналу открывает посещаемость.
- Доступность: обычные ссылки с фокусом клавиатуры, focus-visible, фокус заголовка при переходе, области нажатия не менее 44 px. CSS не переопределяет ограничения доступа по роли.

Браузерная проверка: 320, 390 и 1280 px; отсутствие горизонтальной прокрутки; сохранение незавершённых полей при переключении разделов; отдельные сценарии преподавателя и студента. Проверены существующие сценарии реального API.

Ограничения: это экспертная оценка и автоматизированные браузерные проверки, а не исследование с пользователями. Обновление кабинета по-прежнему перерисовывает серверные формы; переключение разделов их сохраняет. Дальнейшие решения о группировке расширенных настроек стоит проверять на реальных преподавательских сценариях.
